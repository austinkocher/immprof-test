The National Immigrant Women's Advocacy Project has published an  Interactive Public Benefits Map and State-by-State Public Benefits Charts. The map and accompanying charts break down the types of public benefits available to immigrants and the state in which the immigrant resides. There is also a  guide for using these tools.
