The use of Facebook has been in the news.  One organization that has ready access to Facebook’s trove of personal data has a track record of using such information effectively: U.S. Immigration and Customs Enforcement.

ICE uses backend Facebook data to locate and track suspects, according to a string of emails and documents obtained by The Intercept through a public records request. The hunt for one particular suspect provides a rare window into how ICE agents use social media and powerful data analytics tools to find targets.
